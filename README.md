# Physics Simulator 2D

Учебная практика: симуляция физики столкновений в 2D, реализованная с нуля на C++.

Физика реализована самостоятельно: векторная математика, интеграция движения,
поиск столкновений и разрешение контактов. SFML используется для окна, ввода
и отрисовки, Dear ImGui + ImGui-SFML — для панели управления.

## Возможности

- Круги и прямоугольники без вращения (AABB).
- Столкновения circle–circle, circle–AABB и AABB–AABB.
- Импульсное разрешение контактов и позиционная коррекция.
- Статические тела, стены и гравитация.
- Фиксированный шаг физики 1/120 секунды и дополнительные подшаги для быстрых тел.
- Создание шаров мышью с заданием начальной скорости.
- Боковая панель: пауза, пошаговая симуляция, debug-режим и изменение гравитации.
- Отображение FPS, числа тел, контактов и кинетической энергии.
- В debug-режиме — векторы скорости и визуализация контактов.

## Управление

| Действие | Результат |
|---|---|
| `Space` | Пауза / продолжить |
| `N` на паузе | Один фиксированный шаг физики |
| `R` | Сбросить тела и контакты к начальной сцене |
| `D` | Включить / выключить debug-режим |
| Зажать ЛКМ в сцене, переместить мышь и отпустить в сцене | Создать шар в точке нажатия; скорость направлена к точке отпускания и зависит от длины перетаскивания |
| Закрыть окно | Завершить программу |

## Как собрать

### Требования

- Git.
- Visual Studio 2022 с компонентом «Разработка классических приложений на C++»
  (Desktop development with C++), MSVC v143 и Windows SDK.
- vcpkg.

### 1. Подготовить vcpkg

Если vcpkg ещё не установлен, выполните в PowerShell:

```powershell
git clone https://github.com/microsoft/vcpkg.git C:\vcpkg
C:\vcpkg\bootstrap-vcpkg.bat
C:\vcpkg\vcpkg.exe integrate install
```

Если vcpkg уже установлен, используйте свой путь вместо `C:\vcpkg`.
Интеграция с Visual Studio выполняется один раз для пользователя.

### 2. Скачать проект и установить зависимости

```powershell
git clone https://github.com/AdrSm1th/physycs-sim.git
cd physycs-sim
C:\vcpkg\vcpkg.exe install --triplet x64-windows
```

Команду установки выполняйте из корня репозитория, где находится `vcpkg.json`.
Она установит зависимости согласно манифесту в `vcpkg_installed/`.
Эта папка генерируется автоматически и исключена из Git.

### 3. Собрать в Visual Studio

1. Откройте `physycs-sim.sln`.
2. Выберите конфигурацию `Debug` или `Release` и платформу `x64`.
3. Соберите решение: `Ctrl+Shift+B`.
4. Запустите: `F5` или `Ctrl+F5`.

Manifest mode уже включён в проекте (`VcpkgEnableManifest=true`).

Программа загружает шрифт по относительному пути
`assets/Insight Sans SSi.ttf`. Рабочей директорией при запуске должна быть
папка проекта `physycs-sim/`, содержащая `assets/` и `.vcxproj`.
Если появляется ошибка `Font not loaded`, проверьте в свойствах проекта:
**Отладка → Рабочий каталог → `$(ProjectDir)`**.
При отдельном запуске `.exe` также обеспечьте доступность `assets/`
относительно текущего рабочего каталога.
