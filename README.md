# Physics Simulator 2D

Учебная практика: симуляция физики столкновений в 2D, реализованная с нуля на C++.

Физика реализована самостоятельно: векторная математика, интеграция движения,
поиск столкновений и разрешение контактов. SFML используется для окна, ввода
и отрисовки, Dear ImGui + ImGui-SFML — для панели управления.

## Возможности

- Динамические и статические круги и прямоугольники с учётом вращения.
- Столкновения круг–круг, круг–повёрнутый прямоугольник и прямоугольник–прямоугольник.
- Проверка пересечения прямоугольников по SAT (теореме о разделяющей оси).
- Поиск до двух контактных точек для прямоугольников отсечением граней (clipping).
- Итеративное импульсное разрешение контактов с учётом линейной и угловой скорости.
- Трение Кулона, коэффициент восстановления и позиционная коррекция проникновения.
- Гравитация, стены и неподвижные наклонные платформы.
- Фиксированный шаг физики 1/120 секунды и дополнительные подшаги для быстрых тел.
- Создание кругов и прямоугольников мышью с заданием начальной скорости.
- Настройка массы, размеров, цвета, упругости и трения создаваемых тел.
- Выбор тела правой кнопкой мыши, в том числе повёрнутого прямоугольника.
- Инспектор выбранного тела: линейная и угловая скорости.
- Пауза, пошаговая симуляция и изменение гравитации через Dear ImGui.
- Отображение FPS, числа тел, контактных пар и кинетической энергии.

## Физическая модель

Движение интегрируется методом semi-implicit Euler. У каждого тела есть
линейная и угловая скорости, масса и момент инерции. Круг моделируется как
однородный диск, прямоугольник — как однородная прямоугольная пластина.
Тела с нулевой массой используются как статические препятствия.

Контактная пара хранит общие нормаль и касательную. Каждая контактная точка
имеет собственные глубину проникновения, накопленные нормальный и касательный
импульсы и целевую скорость отскока. Импульсы меняют как поступательное движение,
так и вращение тел. Для слабых ударов отскок подавляется порогом скорости.

На каждом подшаге контакты строятся заново, затем выполняются 10 итераций
решателя. Накопление импульсов работает между этими итерациями; переноса
импульсов между подшагами (warm starting) пока нет.

Углы хранятся в радианах, угловая скорость — в радианах в секунду.

## Управление

| Действие | Результат |
|---|---|
| `Space` | Пауза / продолжить |
| `N` на паузе | Один фиксированный шаг физики |
| `R` | Вернуться к начальной сцене |
| `D` | Включить / выключить debug-режим |
| ЛКМ: нажать в сцене, переместить мышь и отпустить в сцене | Создать тело выбранной формы в точке нажатия; скорость направлена к точке отпускания и зависит от длины перетаскивания |
| ПКМ по телу в сцене | Выбрать тело для просмотра скоростей |
| ПКМ по пустому месту в сцене | Снять выбор |
| Закрыть окно | Завершить программу |

Перед созданием тела выберите **Circle** или **Box** на левой панели
**Simulation**. Настройте массу (**Mass**), цвет (**Body color**), коэффициент
восстановления (**Restitution**), коэффициент трения (**Friction**) и размеры:
радиус (**Radius**) для круга или высоту и ширину (**Height**, **Width**) для бокса.
Эти настройки относятся к новым телам, а не к уже выбранному объекту.

На этой же панели доступны **Pause / Continue**, **Step** (на паузе),
**Debug draw** и **Gravity Y**. Положительная гравитация направлена вниз.
Справа расположен **Body inspector** с компонентами линейной скорости
и угловой скоростью выбранного тела. Редактирования тела через инспектор пока нет.
Начальная сцена, включая положения и углы платформ, задаётся в `World::setupScene()`.

## Как собрать

### Требования

- Git.
- Visual Studio 2022 с компонентом «Разработка классических приложений на C++»
  (Desktop development with C++), MSVC v143 и Windows SDK.
- vcpkg.

### 1. Подготовить vcpkg

Если vcpkg ещё не установлен, выполните в PowerShell:

```powershell
git clone https://github.com/microsoft/vcpkg.git C:\vcpkg
C:\vcpkg\bootstrap-vcpkg.bat
C:\vcpkg\vcpkg.exe integrate install
```

Если vcpkg уже установлен, используйте свой путь вместо `C:\vcpkg`.
Интеграция с Visual Studio выполняется один раз для пользователя.

### 2. Скачать проект и установить зависимости

```powershell
git clone https://github.com/AdrSm1th/physycs-sim.git
cd physycs-sim
C:\vcpkg\vcpkg.exe install --triplet x64-windows
```

Команду установки выполняйте из корня репозитория, где находится `vcpkg.json`.
Она установит зависимости согласно манифесту в `vcpkg_installed/`.
Эта папка генерируется автоматически и исключена из Git.

### 3. Собрать в Visual Studio

1. Откройте `physycs-sim.sln`.
2. Выберите конфигурацию `Debug` или `Release` и платформу `x64`.
3. Соберите решение: `Ctrl+Shift+B`.
4. Запустите: `F5` или `Ctrl+F5`.

Manifest mode уже включён в проекте (`VcpkgEnableManifest=true`).

Программа загружает шрифт по относительному пути
`assets/Insight Sans SSi.ttf`. Рабочей директорией при запуске должна быть
папка проекта `physycs-sim/`, содержащая `assets/` и `.vcxproj`.
Если появляется ошибка `Font not loaded`, проверьте в свойствах проекта:
**Отладка → Рабочий каталог → `$(ProjectDir)`**.
При отдельном запуске `.exe` также обеспечьте доступность `assets/`
относительно текущего рабочего каталога.
